# Тренажер игры «Го»

Простой тренажер для игры в Го. Можно сражаться с ботами, изучать основные правила и практиковаться в любое время, в том числе без интернета.

**Открыть тренажер:** https://zlaysobaka.github.io/go-trainer/

## Возможности

- **Игра с ботами.** Сразиться с компьютером и проверить себя.
- **Обучение.** Основные правила игры в одном месте, чтобы начать с нуля.
- **Практика.** Играйте партию за партией и набирайтесь опыта.
- **Уровни сложности.** От спокойной партии для новичка до более сильного соперника.
- **Размеры доски.** Выбирайте доску под свою цель: короткая тренировка или полноценная партия.
- **Любые устройства.** Подходит для телефона, планшета и компьютера.
- **Работает как веб-приложение.** Можно добавить на главный экран и открывать как обычное приложение.
- **Работает без интернета.** После первого открытия сайт сохраняется в кэше устройства и дальше доступен в любых условиях.

## Как начать

1. Откройте сайт по ссылке выше. Первое открытие должно пройти с подключением к интернету.
2. Дождитесь полной загрузки страницы, чтобы сайт сохранился на устройстве.
3. Выберите размер доски и уровень сложности.
4. Играйте или сначала изучите правила.

## Установка как приложение

**iPhone и iPad (Safari):** кнопка «Поделиться» → «На экран “Домой”».

**Android (Chrome):** меню браузера → «Установить приложение» или «Добавить на главный экран».

**Компьютер (Chrome, Edge):** значок установки в адресной строке или пункт «Установить» в меню браузера.

## Работа без интернета

Сайт кэшируется при первом открытии. После этого игры с ботами и обучающие материалы доступны без подключения. Если открыть страницу при наличии интернета, сохранённая версия может обновиться до новой.

## Для разработчиков

Тренажер работает как статический сайт и не требует сервера. Чтобы запустить его у себя, скачайте репозиторий и откройте `index.html` через любой локальный веб-сервер. Для офлайн-режима страница должна открываться по адресу `http://` или `https://`, а не как файл с диска.
